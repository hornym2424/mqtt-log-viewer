file mode

Source

JSONL / JSON配列 / CSV・TSV / テキスト（mosquitto_sub -v 形式）。表へのドラッグ&ドロップも可。

ログ形式（フィールド名）

空欄なら自動判定。ネストは meta.time のようにドット区切り。payload欄が無いログは、残りの項目全体をpayloadとして扱います。

Filter

+ は1階層、# は末尾の複数階層。時刻は 2026-11-15 10:00:00.123 形式（JST）、ISO 8601、UNIX時間。

周期抜け検出

通常間隔は、そのトピックの受信間隔（Δt）の中央値です。5回以上受信したトピックが対象。event・alert など不定期のトピックは、対象トピックで除外してください。
